# BenchBot — La Machine hackathon, Amsterdam, Oct 2026

A voice-controlled second pair of hands for the phone/laptop repair bench, built on the Hugging Face SO-101 arm.
Teach it by showing (record with the leader arm), call it by voice, runs fully offline.

- `benchbot/` — record / replay / listen pipeline (Python, uv)
- `pitch/` — 3-minute pitch script, Q&A prep, and the slide deck (`benchbot_pitch.pptx`, regenerate with `build_deck.js`)

See `benchbot/README.md` for setup.
